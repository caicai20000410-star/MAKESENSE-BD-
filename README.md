# 理然海外BD工作台模版

2026-11-25完整安装包，来源 `3c786a6db5c4c9c5fd3dc2ce4a78aa6e33ae5e2c`。**新安装已内置CRM查重，不需要另打补丁。**

## 新用户完整安装

下载本仓库ZIP并解压，运行 `python3 install.py`（Windows可用 `py -3 install.py`），或使用对应系统启动文件。本机终端输入由提供者线下告知的解压密码；密码仅用于解压，不在聊天中索取。

解压后把 `MAKESENSE-BD/INSTALL.md` 交给已连接Sites的Codex，在自己账号创建仅本人访问的新私人站点，保留空业务库、空个人资料与空飞书凭证。不复用提供者的站点、数据库、对象存储或密钥。

## 已有用户只更新CRM查重

运行 `python3 install-update.py`，在本机输入同样通过线下告知的解压密码。把解压后的 `MAKESENSE-BD-CRM-UPDATE/UPDATE.md` 交给自己工作台的Codex。只增量合并查重，保留自己的配置和数据；不用重新安装。解压器不会覆盖已有目录、登录账号、发布站点或更新线上工作台。

## CRM查重规则

资料采集左侧增加CRM查重，TK、FB、Shopee三输入框同排，至少输入一个，多个按任一ID精确匹配。INS不参与。结果展示三个ID、BD、状态、触达日期、距今天数及提示；按北京时间第21天起算超过20天。查询只读，不保存、不改归属、不操作公共池、不触发采集或同步。未配置自己的飞书授权时显示查重未完成。

工作台保留合同/寄样案例、商品设置、原飞书链接和同步逻辑；团队、纯佣、评论采集、周报生成仍移除。配置自己的飞书凭证后可能读写模版链接的同一外部飞书表。所有者和访问范围由新安装者配置。

需Python3.9+。完整包、增量包分别用release.json和update-release.json校验，所有公开文件哈希见SHA256SUMS。
