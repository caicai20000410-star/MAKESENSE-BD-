# MAKESENSE-BD 双系统安装包

Meta + TikTok 两套独立工作台，使用下载者自己的 GPT/Codex 账号搭建私人 Sites。

**[下载加密安装包](./MAKESENSE-BD.7z)** · **[开始安装](./INSTALL.md)** · [校验信息](./SHA256SUMS) · [验证记录](./VALIDATION.md)

建议下载整个仓库 ZIP 并解压，在 Codex 中打开目录、读取 INSTALL.md。macOS 可运行 `sh 安装.command`；Windows 双击 `安装.cmd`。安装入口需要 Python 3.11+，缺少环境时由 Codex 安装。

1. 安装器校验加密包，提示 **“请输入解压密码”**。密码由提供者线下提供，不在仓库中。
2. 解压后由 Codex 安装依赖和技能，询问 **“请问是否搭建私人工作台（不公开），请回答‘是’”**。
3. 回答“是”后，用你自己的账号创建两个私人 Sites。两站部署成功并核验权限后，提示 **“请前往工作台site进行个人信息设置”**，并列出本次生成的 Meta、TikTok 实际网址。

保留 CRM、合作、自来水、排期、表现、日报/周报、内容资产、评论、便签、合同、寄样、物流、飞书同步、数据通道及各系统现有功能；包含源码、依赖锁文件、空库结构、模板、本机采集/翻译工具，以及 Shopee 采集录入、紫鸟与安装等配套 skills。

初始业务库为空，个人头像、工作台名称、负责 BD 名字未设置。账号凭证、Cookie、原业务记录、历史附件和备份不随包提供。**合同母本和两段可复制案例按提供者要求保留原文，仅放在加密包内。**

需要联网安装依赖，飞书、紫鸟、AI 等外部服务由你配置自己的账号。大型翻译模型约 1.7 GB，按需下载；Windows 本机评论采集/翻译使用 WSL。Sites 插件、账号权限与使用限额以安装者实际账号为准。
