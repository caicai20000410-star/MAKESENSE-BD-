# MAKESENSE-BD

完整 Meta / TikTok BD 工作台的加密交付包，供取得授权的使用者下载并交给 Codex 安装复用。两套系统独立，新部署默认私有，公开须由使用者自己在 Sites 后台操作。

## 下载与安装

下载本仓库中的 `MAKESENSE-BD.7z`。GitHub下载本身无需密码；解压时输入由仓库所有者另行提供的密码。使用支持AES加密7z及文件名加密的7-Zip等工具解压，先核对 SHA256SUMS。

在 Codex 中打开解压出的 MAKESENSE-BD 文件夹，发送：“请读取根 AGENTS.md，按 docs/安装与部署.md 安装完整工作台。两套 Sites 默认私有，完成验收后询问我是否启用每日备份。”

包内包含两套完整应用源码、空库结构、采集扩展、本机评论采集与翻译源码、Shopee Thailand KOL marketing data collection skill、安装说明与默认关闭的每日增量备份模板。各使用者配置自己的飞书、AI、存储和采集账号。无需修改源代码即可在工作台填写业务服务配置。

原工作台业务数据、凭证、Cookie、附件、备份和历史不在包内；按所有者明确要求保留合同与寄样的两段原样可复制案例。寄样Excel仅保留表头和样式。
