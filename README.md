# MAKESENSE-BD 双系统安装包

Meta + TikTok 两套独立工作台，使用下载者自己的 GPT/Codex 账号搭建私人 Sites。

**[下载加密安装包](./MAKESENSE-BD.7z)** · **[开始安装](./INSTALL.md)** · [校验信息](./SHA256SUMS) · [验证记录](./VALIDATION.md)

下载整个仓库 ZIP 并解压，在 Codex 中打开目录并读取 INSTALL.md。macOS 可运行 `sh 安装.command`，Windows 双击 `安装.cmd`；安装器需要 Python 3.11+。

1. 安装器校验加密包，提示 **“请输入解压密码”**。密码由提供者线下提供，不在仓库中。
2. 解压后由 Codex 安装依赖和技能，询问 **“请问是否搭建私人工作台（不公开），请回答‘是’”**。
3. 回答“是”后，用你自己的账号创建两个私人 Sites。两站部署成功并核验权限后，提示 **“请前往工作台site进行个人信息设置”**，并列出本次生成的 Meta、TikTok 实际网址。
4. 一句话：密码是xxx，**是搭建私人工作台（不公开）。**

本版保留 CRM、合作、自来水、排期、数据表现、日报/周报、内容资产、达人管理、便签、合同、寄样、物流、飞书同步及数据通道。人工填写的视频内容、词库与同步逻辑保留，数据表现的评论数统计保留。

按提供者要求移除评论正文功能、视频自动解析和新增的服务配置页面。飞书表链接、商品、寄样与合同的原有默认内容在安装后存在，下载者可自行修改。App ID / App Secret 不携带、不预填，保留授权输入框。

业务库和个人资料初始为空，无账号密钥、Cookie、历史附件和备份。默认内容、合同母本和案例仅包含在加密包内。安装需要联网；不再需要本机评论采集工具、翻译模型或 AI API 密钥。
