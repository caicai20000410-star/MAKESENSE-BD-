# 理然海外BD工作台模版

2026-11-24当前模版完整安装包，来源版本 `a9cdc932ded72a5daa33d81549e0f9a1a9d0afd8`。

下载本仓库ZIP并解压，运行 `python3 install.py`（Windows可运行 `py -3 install.py`）。也可双击对应系统的安装启动文件。

**解压密码由提供者线下告知。安装器仅在本机终端提示输入，不会在聊天中索取密码。密码仅用于解压。**

解压后把 `MAKESENSE-BD/INSTALL.md` 交给已连接Sites的Codex，安装到自己的账号。新工作台默认仅个人可访问的私人站点，不复用提供者数据库、对象存储或密钥。

功能、界面和默认内容来自当前模版；不含业务数据、个人凭证或运行记录。保留合同/寄样案例、商品设置、原飞书表链接及同步逻辑，移除的团队、纯佣、评论采集和周报生成功能保持移除。配置自己的飞书凭证后可能读写模版所链接的同一外部表。

需Python 3.9+；部署由使用者账号的Codex/Sites完成，解压器不自动创建站点。详情见解压后INSTALL.md。
