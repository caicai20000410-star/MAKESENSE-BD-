# MAKESENSE-BD · Meta 个人工作台安装包

基于理然海外 BD 工作台线上第 129 版源码制作。下载整个仓库 ZIP 并解压，在 Codex 中打开目录、阅读 [INSTALL.md](./INSTALL.md)，然后运行 `python3 install.py`（Windows 用 `py -3 install.py`）。macOS 也可运行 `sh 安装.command`，Windows 可双击 `安装.cmd`。

**解压密码由提供者线下告知。** 安装器会在本机终端提示输入，不会在聊天中索取密码。此密码只用于解压；新工作台默认部署为仅本人可访问的私人 Site。

安装者使用自己的 Codex/Sites 账号建立一个 Meta 个人工作台。首次业务库为空；合同母本、两段原样可复制案例、飞书表链接、商品和寄样默认内容保留。团队工作空间、独立 TK 系统、纯佣管理和评论抓取功能不交付；便签内容、达人数据、个人头像、工作台名称、负责 BD 名字及飞书 App ID / App Secret 不随包交付。

部署后，Codex 会提示安装者在新站同步飞书 CLI、填写个人信息，并从工具箱下载和安装谷歌理然达人采集 Chrome 扩展 1.4.9。许可证见 [LICENSE](./LICENSE)。
